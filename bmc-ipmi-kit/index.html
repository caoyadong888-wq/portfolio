BMC/IPMI Fault Code Quick Reference & Runbook

BMC/IPMI 故障码速查与手册

Problem / 问题

SEL noise hides the critical events. Presence, boot, and cleared lines bury the one row that should page someone. Triage is tribal knowledge: the same phrase is cooling on a temperature sensor and a rail on a voltage sensor, and the person who knows the difference is not on every shift.

系统事件日志的噪声会把严重事件盖住。在位、启动和已经解除的行，把真正该叫醒人的那一行埋掉。分诊是口头经验：同一句短语在温度上是散热，在电压上是电源轨，而知道差别的人并不是每个班次都在。

Approach / 做法

A code table maps the sensor type and the event phrase to a severity, a category, and a runbook. A deasserted line drops one severity step. The script groups the capture by host and category, prints the runbook path, and exits 2 while any critical row remains. The flowchart below is the same path on paper. Samples are synthetic hosts only.

码表把传感器类型和事件短语对应到严重级别、类别和手册。已解除的行把级别降一档。脚本按主机和类别汇总，打印手册路径，只要还剩严重项就退出码 2。下面的流程图是同一条路径。示例主机都是合成的。

Triage flowchart / 分诊流程

Collect the SEL and SDR, match the phrase, lower a deasserted line, then open the runbook, schedule a window, or record it. Exit 0 when nothing critical remains. Exit 2 when it does.

先收集 SEL 和 SDR，匹配短语，已解除的降一档，然后打开手册、排窗口，或只记录。没有严重项是退出码 0，还有就是 2。

Demo output / 演示输出

Stdout of python3 demo.py on the two synthetic hosts. The parser reports 59 findings, 19 critical, and exits 2. The demo process then exits 0.

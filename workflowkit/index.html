WorkflowKit

Three n8n templates, run locally

Lead intake, uptime checks, and a daily job-digest. Each file imports with n8n Import from File. The diagrams below are drawn from the workflow JSON.

These workflows were run on a local n8n instance (version 2.41.6). This public page does not run n8n.

Local execution did not call Google Sheets or Slack. A generated test copy rewrote Append Lead Row and Post Lead Notification into HTTP Request nodes pointed at a local mock. Send Email used a local SMTP receiver, and those messages stayed on this machine. Uptime checks used two local mock URLs in place of the published example.com and example.org defaults. The RSS node read the public Jobicy job feed at https://jobicy.com/?feed=job_feed during the local run. Source: Jobicy (jobicy.com), used with attribution. The downloadable JSON files are the full templates: official nodes, no credential ids, and no disabled test nodes. These templates were not submitted to the n8n Creator Hub.

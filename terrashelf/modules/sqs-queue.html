sqs-queue

Queue, dead-letter queue, redrive policy, and server-side encryption.

Tests passed 6 of 6. Failed 0.

Inputs

NameTypeRequiredDescription
dlq_message_retention_secondsnumbernoHow long the dead-letter queue keeps a message, in seconds.
fifoboolnoCreate a FIFO queue and a FIFO dead-letter queue. Both names then end in .fifo.
kms_key_arnstringnoCustomer managed key ARN or alias used when sse_mode is kms. Must be null for SQS-managed encryption.
max_receive_countnumbernoHow many receives the main queue allows before the redrive policy sends the message to the dead-letter queue.
message_retention_secondsnumbernoHow long the main queue keeps a message, in seconds.
namestringyesQueue name without a .fifo suffix. The module appends .fifo when fifo is true, including on the dead-letter queue.
sse_modestringnoServer-side encryption mode. sqs uses SQS-managed keys. kms requires kms_key_arn.
tagsmap(string)noExtra tags merged onto every taggable resource. ManagedBy and Module are always set by the module.
visibility_timeout_secondsnumbernoVisibility timeout for the main queue, in seconds.

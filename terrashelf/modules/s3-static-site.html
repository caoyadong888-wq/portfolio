s3-static-site

Private S3 origin, CloudFront origin access control, and optional access logs.

NameTypeRequiredDescription
access_log_expiration_daysnumbernoDays to keep objects in the module-managed access log bucket.
access_logs_bucket_namestringnoExisting bucket name that receives CloudFront access logs. Null creates a bucket when enable_access_logs is true.
aliaseslist(string)noAlternate domain names on the distribution. Must be empty unless certificate_arn is set.
certificate_arnstringnoOptional ACM certificate ARN. Required when aliases is not empty. CloudFront accepts that certificate only from its global control-plane region.
commentstringnoComment stored on the CloudFront distribution.
default_root_objectstringnoObject CloudFront returns when a viewer requests the root of the distribution.
domain_namestringnoDNS name for the optional Route 53 alias. Null skips the record. When set, it must also be one of aliases.
enable_access_logsboolnoWrite CloudFront standard access logs. Added in 1.1.0. Off by default.
geo_restriction_locationslist(string)noTwo-letter country codes used when geo_restriction_type is not none.
geo_restriction_typestringnoCloudFront geographic restriction type.
kms_key_arnstringnoOptional customer managed key ARN for site bucket encryption. Null uses SSE-S3.
name_prefixstringyesLowercase prefix for the bucket, origin access control, and response headers policy. The module appends a short suffix. Do not encode an environment name here.
price_classstringnoCloudFront price class name. This selects an edge set. It is not a currency amount.
route53_zone_idstringnoHosted zone id for the optional alias record. Set this together with domain_name. Null skips the record.
tagsmap(string)noExtra tags merged onto every taggable resource. ManagedBy and Module are always set by the module.
versioning_enabledboolnoEnable versioning on the site bucket.
web_acl_idstringnoOptional WAFv2 web ACL ARN attached to the distribution. Null leaves WAF off.

account-baseline

Password policy, public access block, EBS encryption, Access Analyzer, and multi-region CloudTrail.

Inputs

NameTypeRequiredDescription
enable_guarddutyboolnoCreate a GuardDuty detector. Default is false because GuardDuty is a billable service.
enable_security_hubboolnoTurn on Security Hub. Default is false because Security Hub is a billable service.
minimum_password_lengthnumbernoMinimum IAM user password length. The module default is 14.
namestringyesName used for the CloudTrail, the trail bucket, and the account analyzer.
tagsmap(string)noExtra tags merged onto every taggable resource. ManagedBy and Module are always set by the module.
trail_log_expiration_daysnumbernoDays before CloudTrail objects in the trail bucket expire.

Added

  • Account password policy, public access block, EBS encryption, Access Analyzer, and a multi-region CloudTrail.
  • Optional GuardDuty and Security Hub switches, both off by default.

github-oidc-role

GitHub Actions role whose trust policy allows one branch or one environment.

Tests passed 6 of 6. Failed 0.

Inputs

NameTypeRequiredDescription
create_oidc_providerboolnoCreate the GitHub OIDC provider. Set false and pass existing_oidc_provider_arn when the account already has one.
existing_oidc_provider_arnstringnoARN of an existing GitHub OIDC provider. Required when create_oidc_provider is false.
github_orgstringyesGitHub organization or user that may assume the role. Wildcards are rejected.
github_repostringyesSingle GitHub repository name that may assume the role. Wildcards are rejected.
inline_policy_jsonstringnoOptional inline policy JSON. Null skips the inline policy. A bare star action is rejected.
managed_policy_arnslist(string)noManaged policy ARNs to attach to the role.
max_session_durationnumbernoMaximum role session duration in seconds.
namestringyesIAM role name. Do not encode an environment into this name.
oidc_thumbprintslist(string)noSHA-1 thumbprints for the GitHub OIDC provider. The provider resource requires at least one.
subject_refstringyesBranch name when subject_type is branch, or environment name when subject_type is environment. Wildcards are rejected.
subject_typestringyesWhether the trust subject pins a branch or a GitHub environment.
tagsmap(string)noExtra tags merged onto every taggable resource. ManagedBy and Module are always set by the module.

Outputs

NameDescription
caller_contextAccount, partition, and region resolved from data sources.
inline_policy_countNumber of inline policies. Zero when inline_policy_json is null.
managed_policy_countNumber of managed policy attachments.
max_session_durationRole max session duration in seconds.
oidc_provider_createdTrue when this module creates the GitHub OIDC provider.
role_arnARN of the IAM role.
role_nameName of the IAM role.
tag_auditTags on every taggable resource this module creates.
trust_audienceExact token.actions.githubusercontent.com:aud value written into the trust policy.
trust_subjectExact token.actions.githubusercontent.com:sub value written into the trust policy.

Example

The caller supplies the region. This example does not embed an account id.

module "gha" {
  source = "../.."

  name         = "gha-demo-role"
  github_org   = "example-org"
  github_repo  = "example-repo"
  subject_type = "branch"
  subject_ref  = "main"
  tags = {
    Example = "basic"
  }
}

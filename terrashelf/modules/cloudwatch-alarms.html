cloudwatch-alarms

Map-driven alarms that publish to an encrypted SNS topic.

Tests passed 6 of 6. Failed 0.

Inputs

NameTypeRequiredDescription
alarmsmap(object({ kind = string threshold = number period = number evaluation_periods = number dimensions = map(string) }))noMap of alarm name to definition. Each entry creates one alarm. Supported kinds are alb_5xx_rate, alb_target_response_time, ecs_cpu, ecs_memory, rds_cpu, rds_free_storage, sqs_oldest_message_age, and dlq_depth.
email_addresseslist(string)noEmail addresses subscribed to the alarm topic. Empty creates no subscriptions.
name_prefixstringyesPrefix for the alarm names, the SNS topic, and the topic key.
tagsmap(string)noExtra tags merged onto every taggable resource. ManagedBy and Module are always set by the module.

Outputs

NameDescription
alarm_action_countHow many actions each alarm is given. Every alarm uses the module SNS topic.
alarm_countNumber of alarms created. Equals the number of entries in alarms.
alarm_namesAlarm names created by this module.
alarm_thresholdsThreshold of each alarm. dlq_depth is forced to 0.
caller_contextAccount, partition, and region resolved from data sources.
email_subscription_countEmail subscriptions on the alarm topic. Zero when email_addresses is empty.
tag_auditTags on every taggable resource this module creates.
topic_nameSNS topic name that receives alarm actions.

Example

The caller supplies the region. This example does not embed an account id.

module "alarms" {
  source = "../.."

  name_prefix = "demo-obs"
  alarms = {
    cpu = {
      kind               = "ecs_cpu"
      threshold          = 80
      period             = 60
      evaluation_periods = 3
      dimensions         = { ClusterName = "app", ServiceName = "api" }
    }
  }
  tags = {
    Example = "basic"
  }
}

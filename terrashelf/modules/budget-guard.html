budget-guard

Monthly cost budget that notifies at 50, 80, and 100 percent.

Tests passed 5 of 5. Failed 0.

Inputs

NameTypeRequiredDescription
email_addresseslist(string)noEmail addresses notified with the SNS topic. Empty notifies only the topic.
limit_amountnumberyesMonthly cost budget amount in USD. Required. Values in examples are placeholders, not recommendations.
name_prefixstringyesPrefix for the budget and the notification topic.
tagsmap(string)noExtra tags merged onto every taggable resource. ManagedBy and Module are always set by the module.

Outputs

NameDescription
caller_contextAccount, partition, and region resolved from data sources.
email_subscription_countEmail subscriptions on the budget topic. Zero when email_addresses is empty.
limit_amountBudget limit as planned. Example values are placeholders, not recommendations.
notification_countHow many budget notifications are configured.
notification_thresholdsPercentage thresholds notified for the monthly budget. Fixed at 50, 80, and 100.
notification_typesNotification types sent at each threshold.
tag_auditTags on every taggable resource this module creates.
topic_nameSNS topic name that receives budget notifications.

Example

The caller supplies the region. This example does not embed an account id.

module "budget" {
  source = "../.."

  name_prefix  = "demo-cost"
  limit_amount = 1
  tags = {
    Example = "basic"
  }
}

ObservaStack

给虚构的生鲜零售商 Larkspur Grocers 写的 Prometheus、Alertmanager 和 Grafana 配置。规则有 promtool 单元测试，路由有 amtool 断言，仪表盘在构建机的 Grafana 上真实导入过。

Larkspur Grocers 是虚构的。这里没有客户、流量、事故或 MTTR。公开页面不运行这些进程。

架构

和 PulseBoard 的区别

维度PulseBoardObservaStack
引擎自研 Python 和 SQLite真实的 Prometheus、Alertmanager、Grafana 配置
告警规则3 条示例，未校验promtool check rules，并且 promtool test rules 覆盖每一条
SLO一条 1 小时可用率规则多窗口、多燃烧率（14.4 / 6 / 3 / 1）加录制规则，可用率和延迟两个 SLI
路由模拟通知日志真实 alertmanager.yml，amtool check-config 和 routes test
仪表盘自绘页面，外加 1 份示例 JSON5 份可导入的 Grafana JSON，构建时真实导入并截图
规则 lint无pint 离线模式，外加策略测试

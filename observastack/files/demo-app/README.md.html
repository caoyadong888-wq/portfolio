# demo-app

Stdlib Python process that exposes `metrics/catalog.yml` as Prometheus text.

Larkspur Grocers is fictional. The numbers in `--dump` are one legal sample per family so `promtool check metrics` can lint the names. They are not a traffic report.

```bash
python demo-app/app.py --dump
python demo-app/app.py   # /metrics and /healthz on port 8080
```

The compose file is not executed on this box (no Docker). `CATALOG_PATH` overrides the catalog location inside the image.

Series whose names look like node_exporter, postgres_exporter, blackbox, Prometheus, or Alertmanager are part of the fixture so the rules and the linter share one catalog. `ALERTS` in this output is not the result of evaluating alerting rules.
